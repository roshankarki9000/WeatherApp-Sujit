# ☁️ Flutter Weather Forecast Demo

## Project Description

This is a demonstration application built for the Flutter Internship evaluation process. The app fetches and displays current weather data and a 7-day forecast for Kathmandu, Nepal, adhering strictly to the provided Figma design specifications.

### Key Technologies

* **Framework:** Flutter
* **API:** Open-Meteo Weather API
* **State Management:** Riverpod

---

## ✨ Features Implemented

* **Current Weather:** Displays the current temperature, precipitation status, and Max/Min temperatures.
* **Hourly Forecast:** Displays hourly temperature and cloud coverage for the current day.
* **7-Day Forecast:** Shows daily Max/Min temperatures and associated weather icons.
* **Air Quality:** Displays the Air Quality Index (AQI) and corresponding health risk level ("2-Minimal Health Risk").
* **Astronomical Data:** Shows Sunrise and Sunset times.
* **UV Index:** Displays the UV Index level and category ("5 - Moderate").
* **Location:** Displays the city name (Kathmandu).

## 🛠️ Instructions to Run the Application

### 1. Prerequisites

Please ensure you have the following tools installed and configured on your machine:

* **Flutter SDK** (Stable Channel)
* **Dart SDK**
* A suitable **IDE** (e.g., VS Code or Android Studio)
* An active **Physical Device or Emulator/Simulator**

### 2. Setup and Installation

Follow these steps in your terminal to get the project running:

1. **Clone the Repository:**
    ```bash
    git clone [https://github.com/roshankarki9000/WeatherApp-Sujit](https://github.com/roshankarki9000/WeatherApp-Sujit)
    cd WeatherApp-Sujit
    ```

2. **Get Dependencies:**
    Fetch all the required packages (e.g., `http`, `intl`):
    ```bash
    flutter pub get
    ```

3. **Check Environment:**
    (Optional but recommended) Ensure your environment is ready:
    ```bash
    flutter doctor
    ```

### 3. Running the App

1. **Start a Device:** Ensure your desired Android Emulator or iOS Simulator is running, or that a physical device is connected.

2. **Execute the Run Command:**
    ```bash
    flutter run
    ```
    *(Alternatively, you can select the target device in your IDE and click the 'Run' or 'Debug' button.)*

## 🌎 API Details

* The application uses the public and unauthenticated **Open-Meteo API**.
* No API keys, environment variables, or other credentials are required to run the application.
